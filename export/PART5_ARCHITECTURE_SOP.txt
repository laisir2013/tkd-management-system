# A. 系統架構總覽
################################################################################

## 技術棧
- 後端: Node.js + Express + tRPC (Type-safe API)
- ORM: Drizzle ORM (MySQL)
- 前端: React 18 + TypeScript + Vite
- UI: Tailwind CSS + shadcn/ui (50+ 組件)
- 資料庫: MySQL 8.0 (30 張表)
- 儲存: AWS S3 (收據圖片上傳/下載)
- 認證: JWT (JSON Web Token) + bcrypt 密碼加密
- 部署: PM2 process manager
- AI: OpenAI API (收據 OCR + AI 對話助手)
- 通訊: WhatsApp Business API (繳費提醒 + 出席通知)
- 即時通訊: Server-Sent Events (考試即時評分)

# B. 功能模組詳解
################################################################################

### 1. 認證系統
- 管理員登入 (電話+密碼)
- 家長登入 (電話+密碼)  
- 教練登入 (電話+密碼)
- JWT Token 認證 (存在 HttpOnly Cookie)
- 角色權限: admin, parent, coach
- 更改密碼功能

### 2. 學生管理
- CRUD 操作 (新增/查詢/修改/刪除)
- 帶級管理 + 歷史紀錄
- 道館分配
- 教練分配
- 狀態管理 (active/inactive)
- 季費設定 ($1,800/季 = $600/月)
- 搜尋篩選 (姓名/電話)

### 3. 繳費系統（核心流程）
- 家長上傳收據 → OCR 自動識別 (金額/銀行/日期/戶名)
- 收據圖片蓋章 (學生姓名 + 金額 + 期別 + 道館名)
- 自動驗證: 金額匹配 + 收款人匹配
- 通過 → 自動確認; 不通過 → 待審批
- 管理員可: 審批待審核 / 手動標記已付 / 撤銷繳費
- 季繳/月繳模式
- 拆分收據處理 (多人合併轉帳)
- FPS / 銀行轉帳 / PayMe / 現金

### 4. 精英班管理
- 獨立學生名冊 (與一般班分開)
- 堂數計費制 (fee_per_class)
- 12堂一個週期
- 出席記錄 (附道館/日期/時間)
- 請假管理 (申請/審批/取消)
- 獨立繳費記錄
- 餘額追蹤

### 5. 出席記錄
- 手動點名 (按道館/日期)
- 月報表匯出
- 教練統計 (含精英班)
- 按月/按道館篩選

### 6. 考試/升級管理
- 考試場次 CRUD
- 報名管理 (添加/移除考生)
- 評分項目配置 (按帶級不同)
- SSE 即時評分 (多設備同步)
- 成績彙總
- 考試出席追蹤

### 7. 會計模組（完整複式簿記）
- **科目表** (Chart of Accounts): 33 個科目
  - 資產: 1001 銀行存款, 1002 應收帳款, 1003 現金
  - 收入: 4001 學費收入, 4002 考試費, 4003 活動費, 4004 商品收入, 4005 其他收入
  - 費用: 5001~5010 (場地租金, 教練費, MPF, 推廣, 攝影, 晚餐, 供應商, 競賽報名, 其他)
  - 負債 + 權益科目
- **映射規則** (Mapping Rules): 18 條
  - 自動將繳費記錄 → 對應借貸科目
  - 支援: 學費(銀行/現金/FPS), 考試費, 活動費, 各類費用
- **日記帳自動生成**: 繳費確認 → accounting_records → journal_entries + journal_entry_lines
- **手動日記帳**: 管理員可手動新增/編輯
- **過帳/反過帳/刪除**
- **財務報表**:
  - 試算表 (Trial Balance) - 借貸必須平衡
  - 損益表 (Profit & Loss) - 收入/費用/淨利
  - 資產負債表 (Balance Sheet) - 資產=負債+權益
  - 總帳明細 (General Ledger) - 逐筆明細
- **銀行對帳**
- **同步功能**: 批量將待處理記錄同步為日記帳

### 8. 活動管理
- 活動 CRUD (名稱/日期/地點/描述)
- 報名管理
- 出席追蹤

### 9. WhatsApp 整合
- WhatsApp Business API 整合
- 範本管理 (CRUD)
- 繳費提醒發送
- 出席通知發送
- 支援多種按鈕 (學生/精英/出席)

### 10. AI 功能
- AI 對話助手 (OpenAI)
- 收據 OCR 識別 (視覺模型)
- 語音轉文字

### 11. 道館管理
- 道館 CRUD (名稱/地址/上課時間)
- 教練分配
- 學生歸屬

### 12. 用戶管理
- 管理員帳號 CRUD
- 角色權限控制

## 繳費 → 會計 完整流程 (已驗證 8/8 路徑通過)

```
路徑1: 家長上傳收據 (OCR自動確認)
  Parent.tsx → uploadReceipt → localOcr.ts (OCR)
    → receiptStamp.ts (蓋章) → 驗證金額+戶名
    → insertPaymentRecord (status='confirmed')
    → syncPaymentToAccounting
    → INSERT accounting_records
    → onAccountingRecordCreated
    → findMatchingRule → generateEntryNumber
    → createJournalEntryFromRecord
    → INSERT journal_entries + journal_entry_lines
    → 自動過帳 (is_posted=1)

路徑2: 家長上傳收據 (驗證失敗→待審批)
  → insertPaymentRecord (status='pending')
  → 管理員 approvePendingPayment
    → syncPaymentToAccounting → ... (同路徑1)

路徑3: 管理員標記已付 (markAsPaid)
  Admin.tsx → markAsPaid
    → insertPaymentRecord (status='confirmed')
    → syncPaymentToAccounting → ... (同路徑1)

路徑4: 管理員確認季繳 (confirmPayment)
  → insertPaymentRecord → syncPaymentToAccounting → ...

路徑5: 管理員確認月繳-季模式 (confirmMonthlyPayment)
  → insertPaymentRecord → syncPaymentToAccounting → ...

路徑6: 管理員確認月繳-月模式 (confirmMonthlyPayment)
  → insertPaymentRecord → syncPaymentToAccounting → ...

路徑7: 精英班建立付款 (elite.createPayment)
  → insertElitePaymentRecord
  → syncElitePaymentToAccounting → ...

路徑8: 手動會計記錄 (accounting.create)
  → INSERT accounting_records
  → onAccountingRecordCreated → ...
```

## 資料庫三層架構
```
Layer 1: paymentRecords / elite_payments
         (原始繳費記錄，含收據URL、學生、金額、狀態)
              ↓ syncPaymentToAccounting
Layer 2: accounting_records
         (會計記錄，含分類、金額、日期、描述)
              ↓ onAccountingRecordCreated
Layer 3: journal_entries + journal_entry_lines
         (日記帳+分錄行，複式簿記借貸雙方)
              ↓
         財務報表 (試算表/損益表/資產負債表/總帳)
```
